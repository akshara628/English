This and These

🔵 Use “this” for one thing that is close to us.

🟢 Use “these” for many things that are close to us.

Look at the pictures. Can you tell which is this and which are these?

This is a pencil.
These are pencils.
This is a cup.
These are cups.
This is a toy.
These are toys.

Easy Rule!

🔵 This: One thing that is near you.

🟢 These: Many things that are near you.
